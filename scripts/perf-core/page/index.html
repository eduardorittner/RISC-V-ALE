RISC-V ALE core benchmark

The driver in scripts/perf-core/run.cjs calls runOne() from this page. Each call runs one repetition of one workload on one core.

The C++ core gets a new worker for each repetition, because its module is one-shot: it runs main at load and stops the runtime at exit. The Rust worker stays alive for the whole session, because the application also calls run_slice many times in one worker. The comment at the top of worker_rust.js explains why the difference matters.
