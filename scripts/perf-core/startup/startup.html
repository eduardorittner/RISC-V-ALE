RISC-V ALE core startup metric

The driver in scripts/perf-core/startup/run_startup.cjs calls runStartup() from this page. Each call is one cold start of one core: a new worker, a new fetch of the module and one run of probe.elf, which writes to the MMIO window on its third instruction.

Both cores get a new worker for each repetition here. A startup figure must be a cold start. The throughput harness keeps one Rust worker for the whole session, for the reason that page/worker_rust.js gives, and that rule is about throughput and not about startup.
